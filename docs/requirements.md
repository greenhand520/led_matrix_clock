## 1. 产品概述

桌面 LED 矩阵时钟：4 块共阳双色 8×8 点阵（32×8 像素画布），大字时间 + 小字秒，
日期滚动动画，时间页/温湿度页整页交替显示（温湿度同屏、按舒适度着色），DS1302 掉电走时，WiFiManager SoftAP 配网，
NTP 开机+周期对时，5516 光敏自动亮度，GPIO0 按键交互，配置持久化到 flash。

## 2. 参考边界与实现约束

- 参考代码是 **MAX7219 + DS3231(I2C) + A0 光感**的另一套硬件方案，只提供功能规格
  （显示什么、如何动画、何时对时）。本项目**不复制其源码、字模表与任何代码文本**，
  全部模块重新设计实现。
- 工程形态：PlatformIO 项目，`framework = arduino`，目标板 ESP8266（ESP-12E/F）。
- **运行模型（定稿）**：单线程协作式——`loop()` + `millis()/Ticker` 驱动的非阻塞
  状态机，不使用 RTOS，不采用 ESP-IDF（ESP-IDF 不支持 ESP8266）。禁止长阻塞
  （`delay()` 仅限启动期短等待）。若未来出现真并发需求（OTA 并行、网络服务、音频），
  优先迁 ESP32-C3（可继续 Arduino 框架），模块划分按可迁移设计。
- 硬约束（源自硬件设计）：
  - 禁用 `Serial1`（GPIO2 = DS1302 SCLK）；调试仅 UART0 115200。
  - 不使用 deep-sleep（GPIO16 = DS1302 I/O）。
  - GPIO12/13/14 作 74HCT595 控制线，不作硬件 SPI。
- 模块划分：

| 模块 | 职责 |
|---|---|
| `src/display/` | 74HCT595 帧输出、TM1640 选通写显存、渲染（像素/字符/动画）、双色帧缓冲、自备字库 |
| `src/rtc/` | DS1302 三线驱动、BCD 编解码、时间读写 |
| `src/sensor/` | DHT11 单总线驱动（3s 采样节拍） |
| `src/net/` | WiFiManager SoftAP 配网、STA 重连、NTP 对时 |
| `src/ui/` | 页面/布局、滚动动画、按键事件、状态提示、舒适度着色 |
| `src/config/` | 配置结构、flash 持久化、默认值/版本/恢复出厂 |
| `src/main.cpp` | 调度（50ms 画帧 / 1s 时间 / 3s 传感 / 15s 换页 / 30min 滚动） |

## 4. 与本硬件的差异（需求调整依据）

| 参考实现 | 本项目 | 影响 |
|---|---|---|
| MAX7219 ×4（SPI + CS，16 级亮度） | TM1640 ×4 + 74HCT595 + 74HCT08 | 显示驱动层全新实现；亮度 8 级 |
| DS3231（I2C，含温度/闹钟） | DS1302（3 线，无温度、无 INT） | RTC 驱动全新实现；C7 不适用；闹钟需软件定时（本期不做） |
| A0 光感（16 级） | A0 + 5516 光敏分压（8 级） | 自动亮度保留，映射 8 档，注意 A0 量程 0–1.0V |
| 单色帧缓冲 | 共阳双色（红/绿） | 帧缓冲双平面；配色规则见 R-UI-09/R-ENV-05 |
| 无温湿度 | DHT11 @ GPIO5 | 3s 采样、TIME/ENV 页 15s 轮换、舒适度着色 |
| 无按键 | GPIO0 按键 | 短按切页、长按 2s 配网、长按 5s 恢复出厂 |
| — | GPIO2 = DS1302 SCLK | 禁用 `Serial1` |

| ID | 需求 | 来源 |

**R-ENV-05 舒适度着色规则**（温度单位 ℃、湿度 %RH；温/湿各自按自身值着色）：

| 等级 | 颜色 | 温度 | 湿度 |
|---|---|---|---|
| 舒适 | 绿 | 18–26 | 40–70 |
| 轻微不适 | 橙 | 12–17.9 或 26.1–30 | 30–39.9 或 71–80 |
| 严重不适 | 红 | <12 或 >30 | <30 或 >80 |

> DHT11 量程 0–50℃ / 20–90%RH，部分红区不可达；规则保持通用以兼容后续 DHT22 升级。
> 若温、湿度等级不同，各按各的值显示；需要整体告警时取较差者（可选项，本期不做）。

## 7. 验收要点

1. 上电 ≤3s 显示时间并正常走时；无网络不阻塞显示。
2. 数字垂直滚动、日期水平滚动（30min 一次）动画流畅，刷新无闪烁。
3. 配色正确：时/分红、秒绿、冒号红闪（开关可配）；12/24h 切换正确。
4. 温湿度每 3s 采样、显示值龄期 ≤3s；页面每 15s 轮换（TIME↔ENV），短按可立即切换；舒适度着色边界正确（用例：17/18/26/27℃，39/40/70/71%）。
5. NTP 开机对时 + 6h 后台对时生效，RTC 与 NTP 一致（±1s）；断网靠 RTC 保持。
6. SoftAP 配网成功后凭据保存、重启自动连 STA；长按 2s 进配网、5s 恢复出厂生效。
7. 配置项掉电/重启后保持；恢复出厂回默认值。
8. 亮度自动跟随光强（8 档、无闪烁跳档）；方向 4 模式显示正确。
9. 24h 连续运行稳定；断电重上电时间连续（CR2032）。

## 9. 已定设计决策记录

- **Q2 落法（v1.1 统一版）**：时间页与温湿度页**整页交替**，统一每 15s 轮换（`page_switch_s`）；
  `default_page` 仅决定上电起始页；温湿度每 3s 采样（显示值龄期 ≤3s）。
  PAGE_ENV 同屏温度+湿度（各按舒适度着色）。独立日期页取消——日期经每 30min
  滚动动画显示（如需独立日期页，加一页即可，不影响其余需求）。
- **舒适度范围**由本基线定义（R-ENV-05 表），可用配置化扩展（本期硬编码常量）。
- **12h 模式**的 AM/PM 显示在小字区与秒同区排布，像素级布局在 UI 详细设计阶段定稿。
- 像素级布局（字号、列坐标、动画曲线）属 UI 详细设计，不在本需求基线内。

## 1. 字库规格

| 类别 | 尺寸 | 样式 | 来源 | 用途 |
|---|---|---|---|---|
| 大数字 | 4×7 | 七段数码管 | 自制取模 0–9 | TIME 时/分 |
| 小数字 | 3×5 | 七段数码管 | 自制取模 0–9 | TIME 秒、ENV 温/湿数值 |
| 小符号 | 3×5 | 七段/自绘 | 自制：`°C` `%` `-` `A` `P`（小数点为 1×1 点，落间隙列） | ENV 单位、负号、12h 标识 |
| 英文/日期 | 5×8 | 常规 | 开源 glcdfont（BSD-3） | 状态提示、日期滚动行 |

- **glcdfont 全量引入（0x20–0x7F），不需要按用字裁剪**：全表仅 96×5 = 480B（PROGMEM），
  而实际文案已覆盖大小写字母+数字+标点（`Wi-Fi`/`OK!!`/`Err!`/`Setup`/`RTC!`、
  日期行），裁剪省不下几百字节，反而要维护字符→索引映射。唯一义务：保留 BSD-3 版权头。
- 七段段位：a/f/b/g/e/c/d；4×7 竖段 2 行、3×5 竖段 1 行、横段满宽。
- 颜色：`OFF / RED / GREEN / ORANGE`（ORANGE = 双色同亮）。

## 2. TIME 页（PAGE_TIME）

31 列主线不变（`4+1+4+3+4+1+4+3+3+1+3`）：

| 元素 | x | y | 字号 | 颜色 |
|---|---|---|---|---|
| 时十位 H1 | 0–3 | 0–6 | 大 4×7 | RED |
| 时个位 H2 | 5–8 | 0–6 | 大 4×7 | RED |
| 冒号 | 点 x=10 | y=2 / y=4 | 1×1×2 | RED，1Hz 闪 |
| 分十位 M1 | 12–15 | 0–6 | 大 4×7 | RED |
| 分个位 M2 | 17–20 | 0–6 | 大 4×7 | RED |
| 间隔位 | 21–23 | — | — | 空置（呼吸间隔） |
| 秒十位 S1 | 24–26 | 2–6 | 小 3×5 | GREEN |
| 秒个位 S2 | 28–30 | 2–6 | 小 3×5 | GREEN |

**AM=GREEN、PM=ORANGE**；24h 无标识；主线 31 列不动（S1 24–26、S2 28–30）。
12h 小时前导 0 不点亮。色块由 `colon` 同款 1×1 点阵拼成，无字模需求。

## 3. ENV 页（PAGE_ENV）—— v0.3：全 3×5，27 列，温度 0.1℃

算式 `3+1+3+1+3+1+3+1+3+1+3+1+3 = 27`，7 槽位 + 6 间隙列；小数点（1×1）落间隙列 x=7：

| 槽位 | 元素 | x | y | 颜色 |
|---|---|---|---|---|
| ① | 温度十位 | 0–2 | 2–6 | 温度舒适度色 |
| ② | 温度个位 | 4–6 | 2–6 | 同上 |
| — | 小数点 | x=7，y=6 | — | 同上 |
| ③ | 温度十分位 | 8–10 | 2–6 | 同上 |
| ④ | `°C` | 12–14 | 2–6 | 同上 |
| ⑤ | 湿度十位 | 16–18 | 2–6 | 湿度舒适度色 |
| ⑥ | 湿度个位 | 20–22 | 2–6 | 同上 |
| ⑦ | `%` | 24–26 | 2–6 | 同上 |

- 温度显示 0.1℃（用传感器协议小数字节；DHT11 小数位恒 0，换 DHT22 即有效）。
- 湿度整数；<10 时十位不点亮；采集失败整组显示 `--`。
- 数值 3s 刷新直接替换，不做滚动。

```
    0    0    1    1    2    2    3
    0    5    0    5    0    5    0
y0  ................................
y1  ................................
y2  ###.###.###.#.#.....###.#.#.....
y3  ..#.#.....#.....#.#.#.....#.....
y4  ###.###.###.###.###.###..#......
y5  #.....#...#.#.....#...#.#.......
y6  ###.#######.###.....###.#.#.....
y7  ................................
```

（示例：左 `25.3°C` 温度色、右 `45%` 湿度色；`°C`/`%` 字形为示意，P3 字模定稿。）

## 4. 日期水平滚动（R-UI-04）

glcdfont 5×8（含其数字），y=0..7，右进左出 50ms/步 ≈6s，每 30min 触发，GREEN（可调）。

## 5. 状态提示覆盖层（R-UI-07）

`Wi-Fi`/`OK!!`/`Err!`/`Setup`/`RTC!`：glcdfont 5×8，y=0..7 水平居中，ORANGE；
`Wi-Fi`/`Setup` 持续、其余 2s；层级：状态覆盖 > 日期滚动 > 页面。

## 6. 自检与页面切换

- 自检：0–0.25s 全屏 RED → 0.25–0.5s 全屏 GREEN → 清屏。
- TIME ↔ ENV 每 `page_switch_s`（15s）轮换；短按立即切换并重置计时，直切。

## 7. 可调项汇总（批注即可）

1. 12h 标识方案甲（3×5 `A`/`P` 右上角，秒组左移）vs 乙（3×2 色块）；甲中 S2(25–27) 与标记(28–30) 相邻，可再右移 1 列留缝
2. `°C`/`%` 字形与大小（现 3×5 自制；可加大到 5×5，ENV 总宽相应加 4 列）
3. 小数点样式（现 1×1 落 x=7、y=6）
4. ENV 行垂直位置（现 y=2–6 与 TIME 秒同基线；整页可居中 y=1–5）
5. 日期行颜色/滚动方向（现 GREEN / 右进左出）
6. 数字垂直滚动方向（现：新字形从上滚入）

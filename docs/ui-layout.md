## 0. 这份稿怎么用

1. **出稿（本次）**：每个元素给出字号、坐标、颜色、动画规则，并渲染像素示例帧。
2. **确认（你）**：直接批注改坐标/字形/配色/方向；示例帧所见即所得。
3. **实现（P3）**：照稿写 `ui_layout.h` 常量表（各元素 x/y/字号/颜色），渲染代码引用常量。
4. **改版**：只改本稿 + 常量表，渲染与驱动代码不动。

示例帧坐标尺：顶部刻度为列号（0–31），行标 y0–y7；`#` 点亮 `.` 熄灭（颜色见各表）。

## 1. 字库规格

| 字号 | 尺寸 | 用途 | 步距（含字距 1 列） |
|---|---|---|---|
| 大字 | 5 列 × 8 行 | 时/分数字 | 6 列 |
| 小字 | 3 列 × 4 行 | 秒、AM/PM、温湿度、日期、状态提示 | 4 列 |

- 字符集 ASCII 0x20–0x7F；字形为自备字库数据（开源 glcdfont 裁剪或自制，P3 落实）。
- 示例帧中的字形为示意，实际以字库数据为准。
- 颜色：`OFF / RED / GREEN / ORANGE`（ORANGE = 双色同亮）。

| 元素 | 字号 | 坐标 | 颜色 | 说明 |

| 温度行 | 小 | `T` x=0..2，数值 x=4..10，`C` x=12..14；y=0..3 | 舒适度色（R-ENV-05） | 整数℃，3s 刷新 |

## 4. 日期水平滚动（R-UI-04）

| 项 | 规则 |
|---|---|
| 文本 | 按 `date_order` 拼接，默认 `YYYY-MM-DD WWT`（如 `2026-10-13 MON`） |
| 字号/位置 | 小字一行，y=2..5（垂直居中） |
| 运动 | 文本从右边缘进入、左边缘移出；50ms/步 x−1；全周期 ≈（文本宽+32）×50ms ≈ 6s |
| 触发 | 每 `date_scroll_min`（默认 30min）一次；滚动期间覆盖当前页，结束回原页 |
| 颜色 | GREEN（可调） |

示例帧（滚动中段，文本起点 x=-8，前两字符已出屏）：

y3  ..#.#.......##..#.#.....##...##.
y4  #...###......#..#.#......#....#.
y5  ###.###.###.###.###.###.###.###.
y6  ................................
y7  ................................

## 5. 状态提示覆盖层（R-UI-07，文案沿用参考项目）

| 文案 | 触发 | 显示时长 |
|---|---|---|
| `Wi-Fi` | 启动联网 / 断线重连 | 持续到出结果 |
| `OK!!` | 联网 / NTP 成功 | 2s |
| `Err!` | 联网失败 | 2s（之后按重试节奏再提示） |
| `Setup` | 进入 SoftAP 配网 | 持续到退出 |
| `RTC!` | 配网超时 | 2s |

- 小字，y=2..5，水平居中（x = (32 − (4n−1))/2 取整）；颜色 ORANGE。
- 层级：状态覆盖 > 日期滚动 > 页面内容。

## 6. 上电自检（R-UI-11）

| 时间 | 画面 |
|---|---|
| 0 – 0.25s | 全屏 RED |
| 0.25 – 0.5s | 全屏 GREEN |
| 0.5s | 清屏 → 进入默认页（`default_page`） |

## 7. 页面切换（R-UI-12）

- TIME ↔ ENV 每 `page_switch_s`（15s）整页轮换；短按立即切换并重置计时。
- 切换方式：直切。
